<h3><b>1. Основы: Гласные и их произношение</b></h3>
<p>📍 <b>Долгие ≠ краткие звуки</b></p>
<ul>
<li><b>Brot</b> (долгий) ≠ <b>Brand</b> (краткий)</li>
<li><b>Sohn</b> ≠ <b>Sonne</b></li>
<li><b>Boot</b> ≠ <b>ob</b></li>
</ul>
<p>📍 <b>Умлауты</b></p>
<ul>
<li>ä → /ɛ/ как в <b>Männer</b></li>
<li>ö → /ø/ как в <b>Öl</b></li>
<li>ü → /y/ как в <b>fühlen</b></li>
</ul>
<p>📍 <b>Дифтонги</b></p>
<ul>
<li><b>ei</b> → /aɪ/ (Leid, Liebe)</li>
<li><b>eu/äu</b> → /ɔɪ/ (Leute, Häuser)</li>
<li><b>ie</b> → /i:/ (Liebe)</li>
</ul>
<hr>
<h3><b>2. Гласные: Важные нюансы</b></h3>
<p><b>E</b> в двух ролях:</p>
<ul>
<li><i>nehmen</i> → /e:/ (долгий)</li>
<li><i>nennen</i> → /ɛ/ (краткий)</li>
</ul>
<p><b>I</b>:</p>
<ul>
<li><i>nie</i> → /i:/ (долгий)</li>
<li><i>innen</i> → /ɪ/ (краткий)</li>
</ul>
<p>🔑 <b>Совет</b>: Обращайте внимание на удвоенные буквы и сочетания для распознавания длины звуков.</p>
<hr>
<h3><b>3. Согласные: Сложности и правила</b></h3>
<p>📍 <b>Часто встречающиеся пары:</b></p>
<ul>
<li><b>s → /z/</b> (в начале слова) → <i>Sonne</i></li>
<li><b>ss/ß → /s/</b> → <i>Straße</i></li>
<li><b>z → /ts/</b> → <i>Zoo</i></li>
</ul>
<p>📍 <b>Сочетания:</b></p>
<ul>
<li><b>sch → /ʃ/</b> → <i>Schule</i></li>
<li><b>tsch → /tʃ/</b> → <i>Deutsch</i></li>
<li><b>st/sp → /ʃp/ и /ʃt/</b> → <i>Sturm</i>, <i>Sport</i></li>
</ul>
<p>📍 <b>Особенности:</b></p>
<ul>
<li><b>ch → /x/</b> после A, O, U → <i>Buch</i>, <i>Nacht</i></li>
<li><b>ch → /ç/</b> после I, E, Ä, Ö → <i>Löcher</i>, <i>Bücher</i></li>
<li><b>v → /f/</b> → <i>Vater</i></li>
<li><b>w → /v/</b> → <i>Wasser</i></li>
</ul>
<p><b>⚠️ Закон конца слога:</b></p>
<p>Звонкие согласные <b>b, d, g</b> на конце читаются как <b>p, t, k</b> → <i>Lob → /lop/</i></p>

<h3><b>4. Ударение: Ключ к пониманию</b></h3>
<p>✅ <b>Общие правила:</b></p>
<ul>
<li><b>90% случаев</b> — ударение на <b>первый слог</b> → <i>Urlaub</i>, <i>ankommen</i>.</li>
<li><b>Префиксы</b>: <i>be-, ge-, er-, ver-, zer-</i> → ударение на корень → <i>verstehen</i>.</li>
<li><b>Иностранные слова</b>: ударение часто на последний слог → <i>Student</i>, <i>Musik</i>.</li>
</ul>
