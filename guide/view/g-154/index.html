Двухчастные уступительные союзы

C1. Недели 60-66

Разбор в чате Gemini

Zweiteilige konzessive Konnektoren — уступка по-немецки на 100%

Ты хочешь подчеркнуть, что есть условие или препятствие,

но оно не мешает главному действию.

Это как сказать: «Хоть он и устал, но он пришёл».

И на немецком для этого есть не только obwohl и trotzdem,

но и особые конструкции уровня C1 — wenn … auch / so, wie … auch.

Что это такое?

Двухчастные уступительные союзы — это конструкции, которые:

  • состоят из двух частей
  • в первой части подчёркивают уступку (хоть..., даже если...)
  • во второй части показывают, что результат всё равно случился
  • чаще встречаются в письменной и формальной речи

Основные модели

1. wenn … auch, so

= хоть..., всё же...

Структура:

Wenn + Subjekt + auch + остальное, so + Verb + Subjekt + ...

Пример:

Wenn er auch müde ist, so macht er doch weiter.

→ Хоть он и устал, но он всё же продолжает.

2. wie … auch

= как бы ни..., всё равно...

Структура:

Wie + прилагательное/наречие + Subjekt + auch + Verb, so + ...

Пример:

Wie sehr er sich auch bemüht, so schafft er es nicht.

→ Как бы он ни старался, всё равно у него не получается.

Сравнение с обычными союзами

Простая форма Двухчастная форма
Obwohl er müde ist, arbeitet er. Wenn er auch müde ist, so arbeitet er.
Egal wie sehr er sich bemüht, er schafft es nicht. Wie sehr er sich auch bemüht, so schafft er es nicht.

Где ставится глагол?

  • В первой части — обычный порядок подчинённого предложения (глагол в конце)
  • Во второй — прямой порядок Hauptsatz

Лайфхаки для запоминания

  • wenn … auch, so = уступка на факте (хоть так, но всё равно)
  • wie … auch = уступка на степени (как бы ни...)
  • Во второй части почти всегда есть doch, dennoch, trotzdem для усиления

Упражнения

Задание 1: Преобразуй предложения с obwohl в конструкции с wenn … auch, so.

  1. Obwohl es regnet, gehen wir spazieren.
Ответ:

Wenn es auch regnet, so gehen wir spazieren.

Объяснение: Заменяем obwohl на wenn … auch, so. Глагол regnet остаётся на втором месте в первой части, а во второй части — прямой порядок (gehen wir).

  1. Obwohl sie keine Zeit hat, hilft sie mir.
Ответ:

Wenn sie auch keine Zeit hat, so hilft sie mir.
Объяснение: Аналогично. Обрати внимание, что so можно заменить на doch (… so hilft sie mir doch).

Задание 2: Используй wie … auch для выражения уступки.

  1. (schnell / er / laufen) – Er kommt zu spät.
Ответ:

Wie schnell er auch läuft, so kommt er zu spät.Объяснение: Wie + наречие (schnell) + подлежащее + auch + глагол. Во второй части — so или trotzdem.

Задание 3: Выбери правильный вариант:

  1. ______ er sich ______ anstreengt, ______ schafft er die Prüfung nicht.
    a) Obwohl / – / –
    b) Wie / auch / so
Ответ:

b) Wie er sich auch anstrengt, so schafft er die Prüfung nicht.Объяснение: Здесь нужна уступка с усилением (как бы ни старался), поэтому wie … auch.
