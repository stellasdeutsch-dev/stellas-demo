Форма Значение Время/аспект Оттенок залога Пример (DE) Перевод

Разные субъекты нет «висящее» причастие Лучше придаточное: Während es regnete, gingen sie …

Ошибки и как чинить

Ошибка Почему плохо Починить
Непонятная связь теряется логика добавь маркер: daher/trotzdem/bei
Перегруз из 3+ групп тяжело читать разбей на 2 предложения
Неверная форма (P1 vs P2) временная путаница «одновременно» = P1, «до этого» = P2
Нет запятых синтаксическая ошибка отделяй группу запятыми

Упражнение: Замени придаточные предложения на Partizipialkonstruktionen

Преобразуй каждое предложение, используя Partizip I или Partizip II, сохраняя смысл.

  1. Während er die Präsentation hielt, улыбался он.
  2. Nachdem sie das Dokument unterschrieben hatte, отправила она его по почте.
  3. Weil er krank war, остался он дома.
  4. Obwohl es regnete, они пошли гулять.
  5. Wenn die Daten richtig ausgewertet werden, дают они полезные выводы.

Ответы и пояснения

Показать ответы
  1. Die Präsentation haltend, lächelte er.

    💬 Одновременность → Partizip I.

  2. Das Dokument unterschrieben, schickte sie es per Post.

    💬 Предшествование → Partizip II.

  3. Krank, blieb er zu Hause.

    💬 Причина → краткая форма с прилагательным от Partizip II (или Adj).

  4. Durchnässt, gingen sie trotzdem spazieren.

    💬 Уступка → Partizip II + маркер «trotzdem».

  5. Richtig ausgewertet, ergeben die Daten nützliche Einsichten.

    💬 Условие → Partizip II в рамочной конструкции.
