<p>Указательные местоимения (Demonstrativpronomen) помогают указывать на конкретный предмет, объект или явление и выделять их из ряда похожих вещей. В немецком языке к этой категории относятся:</p>
<ul>
<li><b>dieser, -e, -es</b> — этот, эта, это;</li>
<li><b>jener, -e, -es</b> — тот, та, то;</li>
<li><b>solcher, -e, -es</b> — такой, такая, такое.</li>
</ul>
<hr>
<h2><b>1. Склонение указательных местоимений</b></h2>
<p>Указательные местоимения изменяются по числу, роду и падежу, как и определённые артикли.</p>
<div class="guide-table"><table> <tr> <td> Падеж </td> <td> Муж. род (der) </td> <td> Жен. род (die) </td> <td> Сред. род (das) </td> <td> Множественное число </td> </tr> <tr> <td> <b>Nominativ</b> (кто? что?) </td> <td> dieser / jener </td> <td> diese / jene </td> <td> dieses / jenes </td> <td> diese / jene </td> </tr> <tr> <td> <b>Genitiv</b> (чей? чьего?) </td> <td> dieses / jenes +(e)s </td> <td> dieser / jener </td> <td> dieses / jenes +(e)s </td> <td> dieser / jener </td> </tr> <tr> <td> <b>Dativ</b> (кому? чему?) </td> <td> diesem / jenem </td> <td> dieser / jener </td> <td> diesem / jenem </td> <td> diesen / jenen +(e)n </td> </tr> <tr> <td> <b>Akkusativ</b> (кого? что?) </td> <td> diesen / jenen </td> <td> diese / jene </td> <td> dieses / jenes </td> <td> diese / jene </td> </tr> </table></div>



<p>- <b>Пример:</b></p>
<ul>
<li><b>Dieser Roman ist spannend. Jener Roman ist langweilig.</b> — Этот роман увлекателен. Тот роман скучен.</li>
<li><b>Dieses Auto ist neu. Jenes Auto ist alt.</b> — Эта машина новая. Та машина старая.</li>
<li><b>Diese Tasche ist teuer. Jene Tasche ist billiger.</b> — Эта сумка дорогая. Та сумка дешевле.</li>
</ul>
<hr>
<h2><b>2. Указательное местоимение „solcher“</b></h2>
<p>Местоимение <b>solcher</b> (такой, такая, такое) склоняется по той же схеме:</p>
<div class="guide-table"><table> <tr> <td> Падеж </td> <td> Муж. род (der) </td> <td> Жен. род (die) </td> <td> Сред. род (das) </td> <td> Множественное число </td> </tr> <tr> <td> <b>Nominativ</b> </td> <td> solcher </td> <td> solche </td> <td> solches </td> <td> solche </td> </tr> <tr> <td> <b>Genitiv</b> </td> <td> solches +(e)s </td> <td> solcher </td> <td> solches +(e)s </td> <td> solcher </td> </tr> <tr> <td> <b>Dativ</b> </td> <td> solchem </td> <td> solcher </td> <td> solchem </td> <td> solchen +(e)n </td> </tr> <tr> <td> <b>Akkusativ</b> </td> <td> solchen </td> <td> solche </td> <td> solches </td> <td> solche </td> </tr> </table></div>



<p>- <b>Пример:</b></p>
<ul>
<li><b>Solcher Mensch kann nichts Gutes tun.</b> — Такой человек не может делать ничего хорошего.</li>
<li><b>Solche Aufgabe könnt ihr zu Hause machen.</b> — Такое задание вы можете выполнить дома.</li>
<li><b>Solches Buch möchte ich haben.</b> — Я хотел бы иметь такую книгу.</li>
</ul>
<hr>
<h2><b>3. Особенности употребления указательных местоимений</b></h2>
<p>1️⃣ <b>Dieser и jener</b></p>
<ul>
<li><b>Dieser</b> — указывает на объект, который ближе к говорящему.</li>
<li><b>Jener</b> — обозначает объект, который дальше.</li>
</ul>
<p>2️⃣ <b>Solcher</b></p>
<ul>
<li>Может употребляться с артиклем: <i>solch ein Haus</i> → <i>такой дом</i>.</li>
<li>Может употребляться без существительного: <i>Ich würde ein solches nie verkaufen</i> → <i>Я бы такое никогда не продал</i>.</li>
</ul>
<p>3️⃣ <b>Der, die, das</b></p>
<ul>
<li>Может использоваться вместо существительного, чтобы избежать тавтологии.</li>
<li><b>Das kenne ich nicht.</b> — <i>Этого я не знаю.</i></li>
</ul>
<p>4️⃣ <b>Derselbe и derjenige</b></p>
<ul>
<li><b>Derselbe</b> — тот же самый: <i>Ich lese dasselbe Buch.</i> → <i>Я читаю ту же самую книгу.</i></li>
<li><b>Derjenige</b> — используется в сложных конструкциях: <i>Derjenige, der das weiß, soll nicht schweigen.</i> → <i>Тот, кто это знает, не должен молчать.</i></li>
</ul>
<hr>
<h2><b>4. Примеры употребления</b></h2>
<p>- <b>Dieser / diese / dieses / diese</b></p>
<ul>
<li><b>Dieser Mann ist sehr intelligent.</b> — Этот мужчина очень умный.</li>
<li><b>Diese Blume ist wunderschön.</b> — Этот цветок прекрасен.</li>
<li><b>Dieses Auto gehört mir.</b> — Эта машина принадлежит мне.</li>
</ul>
<p>- <b>Jener / jene / jenes / jene</b></p>
<ul>
<li><b>Jener Tag war unvergesslich.</b> — Тот день был незабываемым.</li>
<li><b>Jene Stadt ist größer als diese.</b> — Тот город больше, чем этот.</li>
<li><b>Jenes Gebäude ist sehr alt.</b> — То здание очень старое.</li>
</ul>
<p>- <b>Solcher / solche / solches / solche</b></p>
<ul>
<li><b>Solcher Mensch ist selten.</b> — Такой человек встречается редко.</li>
<li><b>Solche Probleme haben viele Leute.</b> — Такие проблемы есть у многих людей.</li>
<li><b>Solches Wetter ist perfekt für den Urlaub.</b> — Такая погода идеальна для отпуска.</li>
</ul>
<p>- <b>Der, die, das</b></p>
<ul>
<li><b>Mit der Kaffeemaschine wirst du zufrieden sein.</b> — С <i>этой</i> кофемашиной ты будешь доволен.</li>
<li><b>Ich nehme dieses Buch, nicht jenes.</b> — Я возьму <i>эту</i> книгу, а не <i>ту</i>.</li>
</ul>
<p>- <b>Derselbe / derjenige</b></p>
<ul>
<li><b>Wir stammen aus derselben Stadt.</b> — Мы из одного и того же города.</li>
<li><b>Derjenige, der zuerst kommt, bekommt einen Preis.</b> — Тот, кто придёт первым, получит приз.</li>
</ul>
<p>- <b>Selbst и selber</b></p>
<ul>
<li><b>Er macht es selbst.</b> — Он делает это сам.</li>
<li><b>Ich kann das selber machen.</b> — Я могу это сделать сам.</li>
</ul>
<hr>
<h2><b>5. Итог</b></h2>
<p>✅ <b>Указательные местоимения помогают выделять объекты или людей.</b></p>
<p>✅ <b>Склоняются так же, как определённые артикли.</b></p>
<p>✅ <b>Dieser — ближе, jener — дальше, solcher — такой.</b></p>
<p>✅ <b>Местоимения derselbe и derjenige используются в сложных конструкциях.</b></p>

<p><b>4.</b> ___ Blume gefällt mir besser als die andere.</p>
<p><b>5.</b> Wir stammen aus ___ Stadt.</p>
<p><b>6.</b> ___ Schüler, der das weiß, soll nach vorne kommen.</p>

<p><b>8.</b> ___ Problem ist sehr schwierig, aber wir müssen es lösen.</p>
